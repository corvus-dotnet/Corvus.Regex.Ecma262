Fortran: API reference

The module corvus_regex_ecma262, generated from its public declarations and their comments by tools/docs/gen-api.ps1. Getting started shows it at work.

Conventions

ECMA-262 (JavaScript) regular expressions for Fortran: a binding to the corvus-regex-ecma262 C library, through ISO_C_BINDING, with the grammar and the answers of RegExp.

A pattern is compiled once into a regex_t, which matches any number of texts, from any number of threads. Text is UTF-8 in a character variable, positions in bytes, or UTF-16 in an integer(int16) array, positions in code units (which may hold lone surrogates). Positions are from 1, and a match_t's start and end are inclusive, so that text(m%start:m%end) is the match; an empty match ends one before it starts.

Every handle frees what it holds when it is finalized. Assigning one regex_t to another compiles the same pattern again; a captures_t may not be copied.

A procedure that can fail takes the optional arguments stat and errmsg, as the intrinsic statements do: stat is CRE_OK or the status of the failure, and errmsg its message. When stat is absent, a failure stops the program with the message (error stop).

Constants

binding_version

character(*), parameter, public :: binding_version = "0.2.5"

The version of this binding.

CRE_EDITION_CURRENT, CRE_EDITION_ES2020

integer, parameter, public :: CRE_EDITION_CURRENT = 0
integer, parameter, public :: CRE_EDITION_ES2020 = 1

The edition of ECMA-262 whose grammar a pattern is read with (the C library's CRE_EDITION_): today's, the default, or ECMAScript 2020's, which JSON Schema 2020-12 names. The 2020 grammar refuses what later editions added: the d and v flags, modifier groups, a name given to more than one group, and property names not in its tables.

CRE_UNICODE_DEFAULT, CRE_UNICODE_13, CRE_UNICODE_17, CRE_UNICODE_18, CRE_UNICODE_LATEST

integer, parameter, public :: CRE_UNICODE_DEFAULT = 0
integer, parameter, public :: CRE_UNICODE_13 = 13
integer, parameter, public :: CRE_UNICODE_17 = 17
integer, parameter, public :: CRE_UNICODE_18 = 18
integer, parameter, public :: CRE_UNICODE_LATEST = int(z'7FFFFFFF')

The version of Unicode whose tables a pattern is read with, independent of the edition (the C library's CRE_UNICODE_): the default, which is the version of the V8 the answers are held to, 13, 17, 18, or the latest the library carries.

unicode_versions, default_unicode_version, latest_unicode_version

integer, parameter, public :: unicode_versions(3) = [13, 17, 18]
integer, parameter, public :: default_unicode_version = 17
integer, parameter, public :: latest_unicode_version = 18

The versions of Unicode a pattern can be read with; the one CRE_UNICODE_DEFAULT stands for; and the one CRE_UNICODE_LATEST stands for.

CRE_OK, CRE_INVALID_ARGUMENT, CRE_INVALID_UTF8, CRE_INVALID_PATTERN, CRE_INVALID_FLAGS, CRE_PATTERN_TOO_LARGE, CRE_MATCH_LIMIT, CRE_PANIC

integer, parameter, public :: CRE_OK = 0
integer, parameter, public :: CRE_INVALID_ARGUMENT = 1
integer, parameter, public :: CRE_INVALID_UTF8 = 2
integer, parameter, public :: CRE_INVALID_PATTERN = 3
integer, parameter, public :: CRE_INVALID_FLAGS = 4
integer, parameter, public :: CRE_PATTERN_TOO_LARGE = 5
integer, parameter, public :: CRE_MATCH_LIMIT = 6

The outcome of a call (cre_status).

Types

match_t

type :: match_t
  integer(int64) :: start = 0
  integer(int64) :: end = -1
  logical :: matched = .false.
end type match_t

Where a match or a group is, from 1, start and end inclusive: text(m%start:m%end). A group that did not take part has matched = .false. (and start 0, end -1).

piece_t

type :: piece_t
  character(:), allocatable :: value
  logical :: defined = .false.
end type piece_t

A piece of a split of UTF-8 text: defined = .false. for a group that did not take part (undefined in the array split returns).

piece16_t

type :: piece16_t
  integer(int16), allocatable :: value(:)
  logical :: defined = .false.
end type piece16_t

A piece of a split of UTF-16 text.

utf8_text_t

type :: utf8_text_t
end type utf8_text_t

A UTF-8 text, checked once when utf8_text makes it, which regex_t's methods search without checking it again: a character argument is checked on every call, a read of the whole text each time. Only utf8_text gives one a text, so it always holds UTF-8; one never assigned from utf8_text is searched as an empty text.

regex_t

type :: regex_t
  ! (procedures below)
end type regex_t

A compiled regular expression. Immutable once compiled: any number of threads may use one at once.

regex_t%compile

subroutine regex_compile(self, pattern, flags, stat, errmsg, timeout, edition, unicode_version)
  class(regex_t), intent(inout) :: self
  character(*), intent(in) :: pattern
  character(*), intent(in), optional :: flags
  integer, intent(out), optional :: stat
  character(:), allocatable, intent(out), optional :: errmsg
  real(real64), intent(in), optional :: timeout
  integer, intent(in), optional :: edition, unicode_version
end subroutine regex_compile

Compiles a pattern with the flags new RegExp(pattern, flags) takes, any of dgimsuvy. On failure stat is CRE_INVALID_PATTERN, CRE_INVALID_FLAGS, CRE_PATTERN_TOO_LARGE or CRE_INVALID_UTF8, and the regular expression is not compiled. timeout is the time in seconds each match may take before it is abandoned with CRE_MATCH_LIMIT (0 for none); without it the regular expression takes default_match_timeout(), which is none unless set. A timeout also caps the backtracking memory of a match; without one a match has no limit of time or of memory, so give a pattern or a text from outside one. edition is the grammar the pattern is read with (a CRE_EDITION_ value, CRE_EDITION_CURRENT without it), and unicode_version the version of Unicode whose tables it is read with (a CRE_UNICODE_ value, CRE_UNICODE_DEFAULT without it); under CRE_EDITION_ES2020 the d and v flags are CRE_INVALID_FLAGS, and another value of either is CRE_INVALID_ARGUMENT. With stat present a failure is not an error stop, so compile with stat and a timeout is the form that checks a pattern without a default timeout.

Procedures

is_valid

function is_valid(pattern, flags, stat, errmsg, edition, unicode_version) result(valid)
  character(*), intent(in) :: pattern
  character(*), intent(in), optional :: flags
  integer, intent(out), optional :: stat
  character(:), allocatable, intent(out), optional :: errmsg
  integer, intent(in), optional :: edition, unicode_version

Whether a pattern is valid with the flags, without compiling it, in the grammar of edition (a CRE_EDITION_ value, CRE_EDITION_CURRENT without it) and under unicode_version (a CRE_UNICODE_ value, CRE_UNICODE_DEFAULT without it). A pattern over a limit of size is not valid here. Another value of edition or unicode_version is CRE_INVALID_ARGUMENT.

utf8_text

function utf8_text(text, stat, errmsg) result(checked)
  character(*), intent(in) :: text
  integer, intent(out), optional :: stat
  character(:), allocatable, intent(out), optional :: errmsg
  type(utf8_text_t) :: checked

The text as a utf8_text_t, checked to be UTF-8 here, once: regex_t's methods then search it without checking it again. A text that is not UTF-8 is CRE_INVALID_UTF8 (last_error_offset is where it stops being UTF-8), and the result holds an empty text.

set_default_match_timeout

subroutine set_default_match_timeout(seconds)
  real(real64), intent(in) :: seconds
end subroutine set_default_match_timeout

Sets the match timeout, in seconds, of every regular expression compiled from now on without one of its own (0 for none, the default). It is the process-wide default of .NET's REGEX_DEFAULT_MATCH_TIMEOUT: a program that matches patterns or texts from outside should set one when it starts. A regular expression already compiled keeps its own.
