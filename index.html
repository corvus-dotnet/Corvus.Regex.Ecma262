Built to answer as ECMAScript does

A pattern written for JavaScript, or taken from a JSON Schema, matches the same texts in every language.

📜

The answers of ECMAScript

ECMAScript 2025: lookbehind, named groups, modifier groups, Unicode property escapes, and the u and v flags. Every engine answers the whole ECMA-262 test data as V8 does, test262 included, with none wrong.

🔤

UTF-8 and UTF-16

One matcher over either encoding, with no transcoding and positions in the units of the text. Text that is not UTF-8 is refused, never read as U+FFFD.

🗓️

ECMAScript 2020 and Unicode versions

The grammar of ECMAScript 2020, which JSON Schema 2020-12 names, and the tables of Unicode 13, 17 or 18, each a setting chosen when a pattern is compiled, at no cost to a match.

⏱️

Bounded in time and memory

A backtracking matcher that remembers where a way has failed, automata for the patterns that need no backtracking, a time limit on every match, and limits of size on every pattern. No pattern can overflow the stack.

⚡

Fast searches for a start

Rare-byte literal searches, Teddy fingerprints and reverse automata find where a match can start, vectorised on x86-64 and arm64 where the language allows.

🔧

.NET: a drop-in with a generator

The shape of System.Text.RegularExpressions, zero allocation per match, and [GeneratedRegex] writing the matcher as code at build time. Read the .NET guide →

In .NET: from pattern to generated code

Put the attribute on a partial method, and the generator writes the matcher as code. The same flags, the same answers, over both encodings.

The .NET guide 
using Corvus.Ecma262.RegularExpressions;

public static partial class Patterns
{
    [GeneratedRegex(@"(?<word>\w+)@(?<host>\w+)\.\w+", "gu")]
    public static partial Regex Email();
}

// Over a string
Match m = Patterns.Email().Match("mail sherlock@baker.st");
string host = m.Groups["host"].Value;                   // "baker"

// Over UTF-8, allocating nothing
ReadOnlySpan<byte> utf8 = "a@b.c and d@e.f"u8;
int n = Patterns.Email().Count(utf8);                   // 2
