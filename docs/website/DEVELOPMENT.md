# The documentation website

The site at https://corvus-oss.org/Corvus.Regex.Ecma262/ is built from this directory by `build.ps1`, on the Vellum
static site generator and the theme of the Corvus.JsonSchema site, which it copies. It has four parts: the home page,
the Getting Started guide (`site/content/GettingStarted`, hand-written), the documentation (the repository's
`docs/design/design.md` and `docs/benchmarks/*.md`, each named by a file in `doc-descriptors/`), and the API reference
(generated from the library's XML documentation by `tools/XmlDocToMarkdown`).

## Building

The build needs the .NET SDK, Node.js, PowerShell 7 and the GitHub CLI signed in to an account that can read the
Vellum releases (`endjin/Endjin.StaticSiteGen`, which is not public: without access the site build is skipped with a
warning). Run it through the repository's build script, which brings the ZeroFailed helpers the Vellum install uses:

```powershell
./build.ps1 -Tasks BuildWebsite            # after a Release build of the solution
./build.ps1 -Website                       # the .NET build, then the site
./build.ps1 -Website -BasePathPrefix /Corvus.Regex.Ecma262   # as GitHub Pages serves it
```

The output is `docs/website/.output/`. `./preview.ps1` serves it at http://localhost:5000.

## In CI

`build.yml` builds the site in the post-compile phase from the compiled library (the ZeroFailed task `BuildWebsite`),
keeps it as the `website-output` artifact, deploys it to the `gh-pages` branch for a stable release tag
(`deploy-docs`), and deploys a preview under `pr-preview/pr-<number>/` for a pull request from this repository
(`deploy-preview`). `gh-pages` holds one commit, which every write replaces (`.github/scripts/Update-GhPages.ps1`).

## Generated and hand-written files

Generated by `build.ps1`, ignored by git: `site/content/Api/*` (but `namespaces/`), `site/taxonomy/api/`,
`site/theme/corvus/views/api/index.cshtml`, `site/theme/corvus/views/Shared/_ApiSidebar.cshtml`,
`site/content/Docs/`, `site/taxonomy/docs/`. Hand-written: `site/source/` (copied into the tree by the build),
`site/content/Home/`, `site/content/GettingStarted/`, `site/content/Api/namespaces/`, the theme's views, SCSS and
scripts.
