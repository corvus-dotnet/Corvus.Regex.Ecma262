# Benchmarks, 2026-10-20: generated code against generated code

Commit 3226ad5. Host: WSL2 on Windows, the VM pinned to the twelve performance cores (vmmemWSL affinity 0xFFF), the run under `taskset -c 0-11` after a three-minute settle, the host probe at 13.4 ns before and 14.7 ns after (12.5 to 16 is the accepted band), .NET 10, BenchmarkDotNet short job, `GeneratedCount`.

The comparison is this library's source generator against .NET's: each Industry workload as a `[GeneratedRegex]` member on both sides, `Count` over the text. The Corvus rows carry the `u` flag (the benchmark adds `gu` to every row, for the interpreter rows too), which .NET has no mode for: classes decode surrogate pairs and the `i` flag folds `s` to the long s and `k` to the Kelvin sign. Counts agree on 53 of the 57 rows; the four apart are `$` and `.` at CRLF, where ECMA-262 counts CR as a line terminator, and `\w`, which .NET takes as Unicode letters and digits.

Since the previous run ([2026-10-19](2026-10-19.md), commit 2d2abe5): the fingerprint search's loop over the vectors with no start is its own method per position count, so its tables stay in registers; a start is verified by one vector compare per form; a literal alternation's verified alternative skips the generated body; the packed search is taken for two literals with a form apart; and the needle's third anchor is lazy (looked at only where the first two agree) and taken wherever a mask joins one.
