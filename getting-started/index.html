Getting Started

The same engine, with the same answers as V8, in every language below. Choose yours: its page shows how to install the package, compile a pattern and match over UTF-8 and UTF-16. Each page lives in its language's repository, whose CI runs the page's code.

.NET The drop-in shape of System.Text.RegularExpressions, with a source generator. dotnet add package Corvus.Regex.Ecma262 C A C ABI over the Rust engine, released as an archive for each platform. find_package(corvus_regex_ecma262) C++ A C++20 binding over the C library, built with CMake. FetchContent_MakeAvailable(corvus_regex_ecma262_cpp) Fortran A Fortran 2018 binding for gfortran and Intel ifx, with fpm and CMake. corvus_regex_ecma262_fortran = { git = "https://github.com/corvus-dotnet/corvus-regex-ecma262-fortran" } Go A pure Go port, for Go 1.25 and later. go get github.com/corvus-dotnet/corvus-regex-ecma262-go Java A Java 17 port with no dependencies. implementation("io.github.corvus-dotnet:corvus-regex-ecma262:0.1.2") Julia A pure Julia port, for Julia 1.10 and later. using Pkg; Pkg.add("CorvusRegexECMA262") Object Pascal A Free Pascal port with no dependencies, written to compile with Delphi too. fpc -Fucorvus-regex-ecma262-pas/src -Ficorvus-regex-ecma262-pas/src yourprogram.pas OCaml A native OCaml port, for OCaml 4.14 and later. opam install corvus-regex-ecma262 PHP A PHP extension for PHP 8.2 to 8.5, installed with PIE. pie install corvus-dotnet/corvus-regex-ecma262 Python A typed package with wheels for Linux, macOS and Windows, from Python 3.10. pip install corvus-regex-ecma262 R An R package, for R 4.2 and later. install.packages("corvusregexecma262", repos = c("https://corvus-dotnet.r-universe.dev", "https://cloud.r-project.org")) Ruby A gem with native builds for Linux, macOS and Windows, for Ruby 3.3 and later. gem install corvus_regex_ecma262 Rust The engine the C library and its bindings are built on, over &str and &[u16]. cargo add corvus-regex-ecma262 Swift A Swift package for Linux, macOS and iOS, over the C library. .package(url: "https://github.com/corvus-dotnet/corvus-regex-ecma262-swift", from: "0.2.3")
